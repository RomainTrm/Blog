- Are you writing down your thoughts ? Paper / blog / linkedin / others
- To me it feels like it is a tought exercise
- feeling of understanding and sometimes mastering a topic
- under impression that I could express/explain it to someone
- in reality it would be a messy demonstration, with a lot of back and forth
- reason: my ideas as a whole seems cohesive, but I cannot express them simutaneously
- writing things forces me to structure my thoughts, to give them a hierachy, a logical path
- some elements of my reasoning needs some predicates, so I need to express theses predicates first
- these logical transitions are usually missing at first
- sometimes it mades me realize that some "logical" connections I imagined are not logical, or completly wrong
- in such cases : my mental model is wrong
- this process is true for me when writing a blog post, it is also true when writing code
- recent example : learning the translator pattern with TEA - I struggled to made a correct mental model of this pattern by solely reading it, I solved it when I managed to code it by myself
- same process on production code : our mental model constently adjusts with the reality of the code
- questioning about intensive AI usage : are we still writing enought ? are we missing important design decisions by not hiting walls ? are our mental models drifting dangerously from reality ?
