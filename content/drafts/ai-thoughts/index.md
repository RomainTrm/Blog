- l'IA change le métier
- l'industrie semble l'avoir adopté sans même se poser la question
- le code n'a plus réellement de coût
- ceux qui ne l'adopte pas sont rapidement dépassés
- certains n'ont pas besoin de l'adopter car les organisations dans lesquelles ils évoluent ne sont pas pretes à accepter un tel boulversement
- ceux qui l'adopte vont potentiellement plus vite
- ceux qui l'adopte perdent quand même
  - l'intéret pour le métier, certains pensent à arrêter
  - transition d'acteur à superviseur à validateur (https://medium.com/@tpierrain/the-hardest-part-begins-when-it-works-408371946988)
  -> désengagement
  -> perte de compétences, plus d'apprentissage de nouveaux skills
  -> le dev devient un consommable facile à remplacer
- on ne lit plus le code
  - je comprend l'argument, la relecture par l'humain devient un bottleneck
  - j'accepte difficilement l'argument : la question de la responsabilité face aux conséquences dans la vraie vie (https://blog.ploeh.dk/2026/10/12/releasing-ai-generated-software/)
- on peut plus rapidement produire
  - de la dette
  - paradoxalement, l'IA repousse le moment où cette dette va nous pénaliser
- l'enjeu est plus que jamais de produire le bon soft
  - avant on réfléchissait à notre cible avant de se lancer dans des développements coûteux
  - maintenant que le code est virtuellement gratuit
    - on peut tester beaucoup d'hypothèse rapidement #bien
    - aller très loin dans la mauvaise direction très rapidement  
- je suis en colère
  - le vol massif de propriété intélectuelle
  - tue tout un écosystème open-source sur lequel on repose tous
  - concentre toutes les capacités de production dans les mains d'une poignées d'entreprise dont l'intérêt n'est pas le notre #dystopie
  - une solution vendue comme une commodité alors que toujours pas viable économiquement
  -> une probabilité non nulle que tout cela s'effondre après avoir profondément abimé notre société
- deux types de personnes (https://danslesalgorithmes.net/2026/10/08/le-travail-intellectuel-est-il-en-train-de-devenir-vain/)
  - ceux qui travaillent pour le résultat -> l'IA est un bénéfice
  - ceux qui travaillent pour le processus (moi) -> perte de sens total dans mon métier, crise d'identité
  -> une porte de sortie de cette crise d'identité que j'entrevois : focus sur les relations humaines avec les clients/utilisateurs, la technique n'aura plus autant de place quoi qu'il arrive
